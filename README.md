# Tatayya - birthday album

1. Copy your photos into the `photos` folder.
2. Open `config.js` and edit the names, photo list, captions and wishes.
   Write a few words under each photo as its caption (or leave it "").
3. In VS Code install the "Live Server" extension, right-click `index.html` -> "Open with Live Server".
4. Online: Render Static Site, no build command, publish directory `.`
